# Rebalanced Prop Moving

Notes on changes to the mod.

Update: 12-22-24

B42 branch support added. Observed from other mods that B42 branch
requires a 42.0 folder. This allows mods to house files for different
version in the same directory structure.

Update: 04-03-26

Added 42.16 version folder with mod.info. Capped 42.13 versionMax at
42.15.0 so version folders don't overlap. Updated workshop.txt
compatibility line to reflect 42.16 support.
